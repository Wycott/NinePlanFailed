# Solution Digest

## Summary

NinePlanFailed implements Kaprekar's routine for 4-digit numbers: repeatedly arranging a number's digits in descending then ascending order and subtracting converges on Kaprekar's constant, 6174, in at most seven iterations. The core logic lives in a reusable class library, a console application drives it across the full 1000-9999 range to report iteration counts, and an xUnit suite verifies convergence for every valid term.
